Required on the target system: ABIv11 (AROS One 1.3 / ABIv11 2026.09), x86_64
Derived from the libraries this BoxerUI opens at start (its autoinit sets)
and the library names in the binary. Presence on any given AROS image has
NOT been checked by this package.

Opened at program start (autoinit; BoxerUI does not start without them):
  exec.library dos.library graphics.library intuition.library
  utility.library diskfont.library cybergraphics.library
  muimaster.library (Zune)
  crt.library stdlib.library m.library   (ABIv11 C runtime)
Opened later by BoxerUI or the SDL code linked into it:
  workbench.library icon.library asl.library datatypes.library
  lowlevel.library oop.library
  timer.device input.device ahi.device (sound)
Not needed: SDL is linked statically (SDL 3, built without OpenGL), so
  no SDL library and no gl.library is required. Such names can appear in
  the binary as text; this build does not use them.
Fonts: Fonts:TrueType/VeraSans.ttf and VeraSansBold.ttf (the system's
  Bitstream Vera Sans; Boxer's Fonts/*.otag refer to them). Without them
  BoxerUI falls back to topaz.font.
Stack: 65536 bytes (set in BoxerUI.info; type "Stack 65536" in a Shell).
