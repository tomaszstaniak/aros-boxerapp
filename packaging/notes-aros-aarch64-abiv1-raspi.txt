
This Raspberry Pi build is a test build. It was tried only under QEMU
(raspi3b, without SMP) on the nightly of 2026-10-29, not on a real
Raspberry Pi. DOS programs run on DOSBox's interpreter core, because the
faster dynamic core does not exist for this processor.

Sound was not heard. Under QEMU, opening the HDMI sound driver hangs the
emulator, so the test used AHI's VOID driver, which discards the sound.
Sound output on a real Raspberry Pi is untested. UnZip is not part of
this system: use the .pkg archive with Unpack.
